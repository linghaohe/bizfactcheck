# Roadmap / 路线图

Prioritize repeated user problems and reproducible evidence. These are candidates, not delivery promises.

按重复出现的真实问题和可复现证据安排优先级；以下为候选，不是交付承诺。

1. Reduce false alarms and missed checks in supported fields; publish additional synthetic regression examples.
2. Improve business scope and period handling while preserving explicit uncertainty.
3. Consider PDF, spreadsheets or slides only when representative public/synthetic cases and extraction-location tests are available.
4. Compare against direct model review and adjacent tools on the same openly documented tasks before making performance claims.

1. 优先修复支持范围内的误报和漏检，补充公开回归样例。
2. 改进业务范围、统计口径与期间处理，保留不确定性。
3. 有代表性公开样例和定位验证后，再评估PDF、表格、幻灯片接入。
4. 用同一组公开任务对比现有工具和直接模型审核，再讨论效果优势。

For adoption, observe GitHub Stars, forks, issues and repeat contributors. Stars are discovery signals, not paying customers or proof of usefulness. No user-document analytics are collected.

关注Star、Fork、Issue与重复贡献；Star反映传播关注，不等于付费客户或效果证明。不收集使用者文档数据。
