# 使用与结果解释

[English](USAGE.md)

## 先选定依据

选择已经确认且适用的资料。若同一字段在多个项目或统计范围中重复出现，先按项目和范围拆分。工具无法替你判断两份冲突资料中哪份更权威。

## 直接核对字段

```bash
bizfactcheck check --source 依据.md --draft 方案.md 交付说明.docx --lang zh --format md --output 核对结果.md
```

支持`字段：值`、`Label: value`和两列表格。每个字段只写一项事实。内置中英别名覆盖项目预算、收入、报告期间、项目阶段、服务期限和服务范围；其他字段只按规范化后相同的标签匹配。同名字段重复出现时会提示歧义，不擅自挑选其中一个。

```markdown
| 字段 | 内容 |
|---|---|
| 项目预算 | 120万元 |
| 报告期间 | 2025年上半年 |
```

支持UTF-8 `.md`/`.txt`和`.docx`正文段落、表格。报告定位是提取后的行或正文位置，不是Word的物理页码。页眉页脚、图形/文本框和修订状态解释不在支持范围内。读取DOCX不会执行宏。首版不支持PDF/OCR、Excel或PPT。

## 核对普通段落

使用Skill整理依据清单，或自行编写JSON。路径相对于清单文件所在目录解析；`value`必须照抄`quote`中的原始片段，不能先换算或改写。

```json
{
  "checks": [{
    "field": "项目预算",
    "kind": "money",
    "source": {
      "path": "依据.md",
      "quote": "已确认项目预算为120万元。",
      "value": "120万元"
    },
    "draft": {
      "path": "方案.md",
      "quote": "方案写项目预算为1.2亿元。",
      "value": "1.2亿元"
    }
  }]
}
```

```bash
bizfactcheck verify checks.json --lang zh --format html --output 段落核对.html
```

可用类型：`auto`、`money`、`duration`、`percentage`、`period`、`status`、`text`。引文缺失、多处重复，或数值不在所引用片段中，会提示复核。字面锚点存在只证明文本出现，不能证明事实真实或两句话属于同一业务范围。适用条件、否定、范围不明和未支持写法应保留人工复核。

程序会检测支持范围内的数值截取错误及部分常见限定、否定表达。这些是有限的词语和边界规则，不是一般自然语言理解。请保留完整上下文；复杂指代、双重否定、可能性表达和数学排版仍需人工核对。

## 支持的规范化范围

- 明确人民币/美元及支持的中英文数量单位，使用十进制比较；不同币种不换汇。
- 支持的持续时间单位；月份和年份不按固定天数处理。
- 百分比与百分点分开处理。
- 已识别的日历年、半年、季度；财年或特殊期间需要复核。
- 明确的项目阶段词汇；阶段变化只提示复核，不证明部署实际发生。
- 不支持的限定词和写法保留为待复核，不删除限定条件后强行匹配。

工具不推导任意算式，不进行汇率换算，不保证实体识别，也不裁定依据的业务权威性。

## 输出与退出码

格式：`text`（默认）、`json`、`md`、`html`。语言：`en`（默认）、`zh`。JSON保留稳定字段名与理由码，面向人的报告采用对应语言。HTML单文件不加载远程脚本、字体或统计服务。

| 退出码 | 含义 |
|---|---|
| 0 | 至少有一对可比较事实，且这些比较未发现差异或待复核项 |
| 1 | 至少有一对可比较事实，同时存在差异或待复核项 |
| 2 | 输入无效、无法读取、不支持，或没有可比较事实；仍可能输出复核原因 |

报告列出未匹配的依据字段、没有对应依据的待审字段等覆盖边界。业务上可能允许省略字段，因此缺失不自动算错。不要将部分字段的比较说成整份文件已检查通过。

`--output`只创建**新**报告，拒绝覆盖已有路径、输入文件和符号链接。不指定时，报告输出到终端。报告包含原文片段，请按原资料的敏感级别保存。
