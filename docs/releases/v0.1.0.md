# BizFactCheck v0.1.0 — Business fact consistency review / 业务事实核对

**Before sending a proposal, check whether its budget, reporting period, and project stage still agree with the approved reference.**

**方案发出去之前，先检查预算、统计期间和项目阶段是否与依据一致。**

For example / 业务示例：

| Reference / 依据 | Draft / 待审内容 | Result / 核对结果 |
|---|---|---|
| 120万元 / CNY 1.2 million | 1.2亿元 / CNY 120 million | Amount differs / 金额不一致 |
| 2025 H1 / 2025年上半年 | 2025 / 2025年全年 | Period differs / 统计期间不一致 |
| Prototype / 原型 | Deployed / 已部署 | Human review / 需要人工复核 |
| 24 hours / 24小时 | 1 day / 1天 | Equivalent supported duration / 支持范围内的等价时间 |

The examples are synthetic. They do not establish accuracy on customer documents.

以上是自造案例，不代表真实客户材料上的准确率。

## Included / 本次发布

- Offline Python CLI for labeled Markdown/TXT fields and DOCX body paragraphs/tables.
- Evidence-manifest verification for pairs extracted from prose, with quote and value anchors.
- English/Chinese text, JSON, Markdown and standalone HTML reports.
- A portable agent skill, synthetic examples and regression tests.
- 本地运行的字段核对程序，支持Markdown/TXT与DOCX正文和表格。
- 面向普通段落的依据清单校验，检查引文与取值是否确实出现在文件中。
- 中英文报告与独立HTML文件；配套skill、自造案例和回归测试。

## Try it / 开始使用

Read the [English introduction](https://github.com/linghaohe/bizfactcheck#readme) or [中文介绍](https://github.com/linghaohe/bizfactcheck/blob/main/README.zh-CN.md) for the one-minute example.

Download the wheel below and install it with Python 3.9+:

```bash
python -m pip install bizfactcheck-0.1.0-py3-none-any.whl
bizfactcheck --help
```

The separate `bizfactcheck-skill.zip` contains the skill instructions. Install the Python package as well; the skill does not include a model or automatically install the CLI.

下方wheel文件可直接安装；单独的skill压缩包只包含技能说明，使用前仍需安装Python程序。模型与客户端由使用者自行选择。

## Limits / 边界

Alpha release. Only reported comparisons are checked. The selected reference may be wrong; matching quotes do not prove matching business scope. Changed scope/stage needs review. PDF/OCR, Excel, PowerPoint and complex arithmetic are not supported. A cloud assistant using the skill has its own data-handling settings even though the CLI is offline.

当前为alpha版本，只核对报告列出的比较项。依据本身可能有误；引文存在不等于业务口径一致。范围或阶段变化仍需人工确认。暂不支持PDF/OCR、Excel、PPT和复杂计算。CLI离线运行，使用云端助手时仍须关注其自身的数据处理设置。

Please share a minimal **synthetic** reproduction in Issues. Never upload confidential business files. If useful, a Star helps others discover the project.

欢迎在Issues反馈最小**自造**复现案例，请勿上传保密业务文件。如果工具对你有帮助，欢迎点Star。
