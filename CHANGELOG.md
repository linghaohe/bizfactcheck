# Changelog / 更新记录

## 0.1.0 — 2026-11-15

- Initial alpha: local labeled-field checking and quote-anchored evidence manifests.
- Supported amount, duration and calendar-period normalization; explicit review findings for changed stage, text or ambiguous evidence.
- Markdown/TXT and DOCX body/table extraction; English and Chinese text, JSON, Markdown and standalone HTML reports.
- Portable agent skill, fictional bilingual business examples and regression tests.
- 本地字段核对、引文锚定清单、金额/时间期间比较及明确的人工复核提示。
- 中英双语介绍、业务样例、报告和配套Skill。

Real customer accuracy, broad document-format support and cross-host skill compatibility are not established by this release. 真实业务准确率、更多文件格式和所有助手的技能兼容性仍待验证。
